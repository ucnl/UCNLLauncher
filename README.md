# UCNL Launcher

Android-приложение на .NET 8 MAUI (`net8.0-android`, минимальный Android 5.0 / API 21, целевой API 34). Оболочка с WebView: локальное меню `Resources/Raw/launcher.html` запускает веб-приложения UC&NL (Zima2, uWave, RedPhone-DX Config, uGNSS-Monitor, uConsole), которые загружаются с docs.unavlab.com в локальный кэш и работают офлайн.

Нативная часть даёт веб-приложениям доступ к USB-serial устройствам, GPS и компасу, сохранение файлов и очистку кэша. Меню и панель настроек (тема, язык, очистка кэша) находятся в `launcher.html`.

## Сборка

Нужны .NET 8 SDK с workload `maui-android`, JDK 17 и Android SDK 34.

```
dotnet build UCNLLauncher.csproj -c Debug -f net8.0-android
```

Подпись релизной сборки задаётся в `signing.props` (в репозиторий не попадает). Шаблон — `signing.props.example`: скопируйте его в `signing.props` и укажите путь к keystore, алиас и пароли.

## Темы

Настройка «Тема» в панели настроек: «Системная» (по умолчанию), «Светлая», «Тёмная». Выбор сохраняется. В режиме «Системная» смена темы устройства применяется без перезапуска. Тема действует на меню, нативную панель с кнопкой «Назад», индикатор загрузки, системные status bar и navigation bar, диалоги. Цвета лаунчера заданы CSS-переменными в двух блоках `:root[data-theme="..."]`, нативные — ресурсами `Resources/Styles/Colors.xaml`.

## Локализация

Все пользовательские строки лежат в словарях `Resources/Raw/i18n/<код>.json`: плоский JSON-объект «ключ — строка», UTF-8 без BOM. Служебный ключ `_name` — название языка на самом этом языке (оно показывается в списке). Подстановки записываются как `{0}`, `{1}`. Словари читают и нативная часть, и `launcher.html`; внешних библиотек нет.

Правило выбора языка: при настройке «Системный» берётся язык системы, если для него есть словарь (сначала полный тег, например `pt-BR`, затем только язык, `pt`); иначе английский. Если ключа нет в выбранном словаре, берётся английская строка, а при её отсутствии показывается сам ключ. Язык меняется на лету, в том числе при смене языка системы.

### Как добавить язык

1. Скопируйте `Resources/Raw/i18n/en.json` в `Resources/Raw/i18n/<код>.json`. Код языка — по BCP 47 в нижнем регистре: `de`, `fr`, `pt-BR`, `zh-Hant`.
2. Переведите значения. Ключи не меняйте. Подстановки `{0}` сохраняйте. Названия продуктов не переводятся.
3. Замените значение `_name` на название языка на нём самом, например `Deutsch`.
4. Проверьте: `python tools/check_i18n.py`. Скрипт сверяет набор ключей и подстановки с `en.json`, ищет ключи, которых нет в английском словаре, и зашитые кириллические строки в коде.
5. Пересоберите приложение. Файл попадает в APK автоматически, язык появится в списке настроек. Правка кода, разметки и `UCNLLauncher.csproj` не нужна.
